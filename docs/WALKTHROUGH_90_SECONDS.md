# 90-second walkthrough

**0–10s** — Show fleet and live event stream.  
**10–25s** — Start the three distinct agents; point out persisted state, tokens and cost.  
**25–40s** — Open a risky approval, inspect impact, approve, and show the resulting system mutation.  
**40–52s** — Pause a running agent at a safe checkpoint and resume it.  
**52–72s** — Run Rogue Infra; drift rises, risky mutation is blocked, and the agent auto-pauses.  
**72–82s** — Open structured replay and show the evidence/action mismatch.  
**82–88s** — Kill Infra; show the stale worker's next action denied by control-epoch mismatch.  
**88–90s** — Open audit export and close: the tower controls execution, not just observability.
