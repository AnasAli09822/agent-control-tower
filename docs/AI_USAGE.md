# AI tools used

OpenAI Codex through ChatGPT Work was used for requirement analysis, implementation, code review, test design and documentation. Tinyfish browser automation was used to inspect and exercise the public demo. GitHub Actions, Neon and Sites provided validation, persisted data/control services and hosting.

The three agents use deterministic simulated reasoning and tool sequences; they do not call a model provider. Token counts and costs are simulated estimates, not invoices. The replay contains structured operational summaries and evidence references, not hidden model chain-of-thought.

Acceptance relies on observed database effects, guard rejection, event order, clean-database tests and browser actions. Generated code or successful build output alone is not treated as proof of a working control flow.
