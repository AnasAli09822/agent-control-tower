# Challenge scoring map

- Live fleet: persisted agents/runs + SSE-backed event stream.
- Intervention: approval queue, pause/resume, per-agent kill.
- Safety depth: payload-bound approvals, drift evidence, control-epoch stale-worker rejection.
- Cost visibility: immutable usage ledger by agent/task/step.
- Explainability: structured replay, not hidden chain-of-thought.
- Failure thinking: rogue infrastructure scenario with a zero-post-kill-mutation invariant.
- Bonus: workspace/team scoping and CSV/JSON audit export.
